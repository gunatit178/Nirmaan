# Fonts

`khastakshar.woff2` is **Khastakshar** (Normal, version 3.000) by
**Bhaumik Suthar**, Atelier Kutch, Ahmedabad.

Khastakshar © 2026 by Bhaumik Suthar is licensed under
[CC BY-ND 4.0](https://creativecommons.org/licenses/by-nd/4.0/).

It is the original font, unmodified: every glyph and feature is kept. The
only change is the file format (TTF → WOFF2, a lossless technical conversion
for the web, which the licence allows). Do not subset, edit or re-draw it;
"no derivatives" means those changes need the author's permission. The site
credits the font in the footer, as the licence requires.

Used for the Gujarati words નિર્માણ ("to build") and નિર્માન ("without ego")
on the homepage. `styles.css` loads it with a Gujarati-only `unicode-range`,
so pages without Gujarati text never download it.
